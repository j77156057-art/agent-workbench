Two-Phase Architecture

两阶段，从「会查文档」到「改得动仓库」

不是把大模型塞进编辑器，而是先给你的工程一本本地知识库，再给它一套能安全落盘的仓库级工作台。

PHASE 01

本地 RAG + ReAct Agent

  • 离线索引工程文档、代码与配置
  • ReAct 推理循环：检索 → 决策 → 执行工具
  • 弱模型友好的工具调用归一与失败护栏
  • 所有上下文留在本地，不外发
PHASE 02

仓库级工作台

  • 分区管理：按 audio / values / assets / behaviors 隔离
  • 每区独立 git + 契约治理，改动可回滚
  • 引擎嵌入（Godot 等）+ 场景画布
  • 多项目体系，并行而不串味

Realtime Multimodal Engine

实时多模态对话引擎

语音即输入、画面即上下文、打断即响应、断线自恢复。以下为 R12 真机联验实测，非 PPT 数字。

六项被真机验证的硬能力

  • 语音即输入：16kHz PCM16 麦克风上行
  • 画面即上下文：摄像头 / 屏幕共享进模型视野
  • 打断即响应：说一半就停、自动取消在播音频
  • 静音尾收句：停说后补约 1s 静音让 VAD 干净收句
  • 断线自恢复：stream_broken 自动重连重放
  • 音频先行闸门：先音频后图像，绕过供应商硬约束
