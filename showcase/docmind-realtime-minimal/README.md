# DocMind · 实时视频对话引擎 · 极简版本（Alternative）

与 `showcase/docmind-realtime/`（复古未来 · 暗色霓虹仪表台）**同一份内容、另一套调性**，便于对比选型。

## 设计定调

| 维度 | 决策 |
|---|---|
| **调性** | 极简克制（Brutally minimal）· 暖纸白底 |
| **展示字** | `Bricolage Grotesque`（非禁用清单） |
| **正文** | `Work Sans` + 中文 `Noto Sans SC` |
| **数据** | `JetBrains Mono`（品牌同源） |
| **主色** | 暖纸白 `#f3f1ea` + 墨 `#16130d` |
| **强调** | 品牌青的浅色适配 `#0c8c7e`（源自 `theme.ts` region.audio，加深以满足 AA 对比）；原青 `#2ec4b6` 仅作装饰 |
| **手法** | 发丝线分隔、大留白、单一强调色、无辉光无扫描线无颗粒 |

## 与暗色版的差异

- 暗色版：近黑底 + 霓虹辉光 + CRT 扫描线 + 渐变网格 + 颗粒，氛围浓烈。
- 极简版：纸白底 + 发丝线 + 大留白，靠排版与间距制造高级感，无氛围层。
- 两者共享同一 HTML 结构、同一真实 R12 数据与能力点，仅 CSS/令牌不同。

## 反 AI 味自检

展示字非禁用清单 ✅；非白底紫渐变 ✅；非居中三卡（非对称 HERO + 线框控制台）✅；动效编排错峰 ✅；有记忆点（线框控制台）✅；对比度 ≥4.5:1、焦点圈、降级动效、响应式 980/620 两档 ✅。

## 运行

浏览器直接打开 `index.html`。
