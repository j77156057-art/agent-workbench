# Agent 工作台 · 实时视频对话引擎 · 工业控制台版本（Industrial）

四版对照中的第三版。与 `showcase/docmind-realtime/`（暗色霓虹复古未来）同为暗色，但气质相反：
- v1 霓虹版：辉光、渐变网格、CRT 扫描线、颗粒——**氛围浓烈**。
- 本版工业版：扁平、无辉光、靠**密度 + LED 状态色 + 等宽遥测**制造「任务控制台」感。

## 设计定调
- 调性：Industrial / 任务控制台（mission control）
- 字体：展示 `Archivo` + 正文 `IBM Plex Sans` + 数据 `JetBrains Mono` / `IBM Plex Mono`
- 配色：冷调近黑 `#0b0e13` + 扁平表面；强调品牌青 `#2ec4b6`；LED 状态色（绿/琥珀/红/青/紫）用于真实状态语义
- 手法：发丝线网格、密集遥测条、状态 chip 带 LED 指示点、顶部细状态条；零氛围层
- 顶部新增一条遥测状态条（ENGINE/MODE/UPLINK/SESSIONS/LATENCY），强化「控制台」叙事

## 反 AI 味自检
展示字非禁用清单 ✅；非白底紫渐变 ✅；非居中三卡 ✅；动效编排 ✅；有记忆点（控制台 + 遥测条）✅；对比度/焦点/降级/响应式 ✅。
