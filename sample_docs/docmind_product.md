# Agent 工作台 智能文档助手 · 产品说明（示例知识库）

Agent 工作台 是一款面向团队的知识库问答助手，支持把公司文档、手册、FAQ 上传后，用自然语言提问并即时获得答案。

## 核心功能

1. 文档上传与解析：支持 PDF、Markdown、TXT 三种格式，自动切分并建立向量索引。
2. 知识库检索：基于向量相似度召回最相关的文档片段，保证答案有出处。
3. Agent 推理：问答过程不是简单拼接检索结果，而是由大语言模型自主决定调用检索、计算或联网工具。
4. 多模型支持：后端通过 OpenAI 兼容协议统一接入通义千问、DeepSeek、Ollama 本地模型，可在配置中一键切换。

## 计费与配额

免费版每个工作区最多上传 100 个文档，单文档不超过 20 MB。专业版支持无限文档与团队共享空间，按席位按月订阅。

## 常见问题

问：支持哪些文件格式？
答：目前支持 PDF、Markdown(.md) 和纯文本(.txt)。

问：答案的准确率如何保证？
答：系统采用检索增强生成（RAG），所有回答都基于知识库检索到的真实片段，并可回溯来源文档。

问：数据是否安全？
答：文档默认仅存储于所属工作区，企业版提供私有化部署与密钥加密。

## 使用建议

为了让 Agent 给出更准确的回答，建议上传结构清晰、章节分明的文档，并在提问时尽量包含具体关键词。
