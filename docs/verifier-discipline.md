# 判据纪律：一份判据在**什么条件下**才算有效

> 与 `docs/research-discipline.md` 分开：那份管**信息来源**可不可信，
> 这份管**判定规则**会不会骗你。
>
> **同一晚连栽四次**（2026-10-10，写意图那一族），四次形态不同、
> 同一个病根，所以单独立档。

## 为什么要有这份东西

我当晚做的是「量化某个修法的代价」—— 写一个探针，
把候选改法接上去，数「修好几句 / 误伤几句」。

**这个动作看起来很严谨。它骗了我四次。**

四次里有三次我差点把结果当结论报出去，
一次已经报了（「多个方案零误伤」），靠后续步骤才发现不对。

## 病根一句话

> **没有覆盖的判据，不能算通过。**

「误伤 0」在两种完全不同的情况下成立：

* 真的测过了，一个都没伤
* **根本没测到那里**（语料里没有那种句子）

第二种和第一种在数字上**一模一样**。

## 四个真实的坑（按发生顺序）

### 坑 1：语料提取返回空，照算不误

从 `test_write_intent_predicate.py` 取「必须 denied」语料，取到 **0 条** ——
那里**只有一句注释**提到那个常量名，没有定义。

我没有检查，照着用空列表算，于是**每个方案都报「误伤 0」**，
并据此认为「A/B/D/G/H 五个方案都可用」。

真值：用干净语料重算，**A 误伤 4 句、C 误伤 1 句**。

**空列表必报 0 误伤。任何以此为据的结论都无效。**

### 坑 2：文本正则把注释散文当语料

改用文本正则切列表。那两个列表里有**多行注释**，
正则把注释里的引号内容也当成了元素：

```
{question!r} 是审查/问答，不是写授权，却被判成有写意图 ——
反向守卫：新词不能把否定作用域破坏掉。
```

于是「误伤 1 句」其实**是一条断言消息**，不是语料。
而误伤数字偏小 → 我会去选一个实际会误伤的方案。

**提取语料必须用语法（`ast`），不能用文本正则。**
文本正则分不清「列表里的元素」和「注释里的引号」。

### 坑 3：排除表可消融 = 它在装样子

我造了一个 9 词排除表（操作/工具/方式/失败/方案/工具箱/过程/流程/机制），
配「句首动词」判据，结果 **5/5 修好 + 0 误伤**。看起来是完美方案。

**做消融才发现：逐个删掉这 9 个词，任意一个删掉都不影响结果。**
即那张表**完全没有起作用** —— 真正区分两组的是「句首」本身。

而「句首」单独用，在反向语料上误伤 **9/14**
（「写规范」「设计原则」「实现成本」这些纯名词短语也是句首）。

**判据里的每一部分都要能通过消融证明自己有用。
消融不掉的部分是凑数的，会让人误以为覆盖到了。**

### 坑 4：拿真实语料的名义，测的还是零覆盖

从 `agent_memory` 的 sqlite 挖出 114 条真实用户提问（trace 因隐私只存
`question_chars` 不存原文），换掉测试自带的语料重跑。

结果**所有方案都报「真语料误伤 0」**，包括此前在测试语料上误伤 5 句的
「全裸加」。

查覆盖率才发现：

| 覆盖项 | 条数 |
|---|---|
| 真实提问（去重） | 61 |
| 含「写」 | **0** |
| 含「设计」 | **0** |
| **句首是这三词之一** | **0** |

**那片语料对这条边界零覆盖。** 那 61 条长这样：`你好`、
`今天的天气怎么样`、`你是什么模型`、`【语音指令】什么金？`。

零覆盖下的「误伤 0」是**没有信息**，不是「安全」。
它和我前三次是同一个错误的不同外衣 —— **我拿它当通过证据了**。

## 可执行的规则

### 写探针前

1. **语料非空断言**：提取到 0 条就直接退出，不许继续算。
   退出码非 0，不是 0。
2. **语料来源标注**：打印它来自哪个文件、多少条。
   「我自己造的」必须显式标出 —— 自造语料验自造判据是循环论证。
3. **看覆盖率，不只看条数**：打印「目标形状命中几条」。
   0 条命中 → 这片语料**测不到这条边界**，结论无效。

### 算完结果后

4. **消融**：判据的每一部分逐个去掉重跑。消融不掉 = 凑数。
5. **反向语料**：造一批「同一形状但结论相反」的句子。
   自己造的反向语料也要标出来它是自造的。
6. **两个方向都要报**：修好 N 句 + 误伤 M 句。
   只报「误伤 0」的实现方式本身可疑。

### 报告结论时

7. **写清判据的适用边界**：
   「在这 22 句语料上 0 误伤」≠「安全」。
   要写「语料只覆盖 X 两种形状，Y 形状未测」。
8. **零结果要怀疑，不要庆祝**：
   「误伤 0」和「测试根本没跑到那里」在输出上完全一样。
